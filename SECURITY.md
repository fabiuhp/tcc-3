# Segurança

## Escopo suportado

Este é um protótipo acadêmico voltado para execução local. Somente a branch `main` e a release mais recente, quando houver, recebem correções.

O frontend não possui autenticação, autorização ou TLS. Não exponha o servidor diretamente à internet ou a redes não confiáveis.

## Relatando uma vulnerabilidade

Use o [relato privado de vulnerabilidade do GitHub](https://github.com/fabiuhp/tcc-3/security/advisories/new). Não abra uma issue pública com detalhes exploráveis, credenciais ou dados pessoais.

Inclua, quando possível:

- descrição e impacto;
- passos mínimos para reprodução;
- versão ou commit afetado;
- sugestão de correção, se houver.

O mantenedor responderá em regime de melhor esforço. Não há SLA de suporte para este projeto acadêmico.

## Dados sensíveis

Áudios, transcrições e requisitos podem conter dados pessoais ou informações confidenciais. Use somente dados para os quais exista autorização adequada, mantenha o MongoDB restrito ao ambiente local e remova os artefatos quando não forem mais necessários.
